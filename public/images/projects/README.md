# 프로젝트 이미지 업로드 폴더 (Project Images Directory)

이 폴더는 포트폴리오의 **프로젝트 썸네일 및 상세 이미지**가 위치하는 폴더입니다.
원하시는 실제 사진/이미지 파일을 아래 파일명으로 이 폴더에 넣어주시면, 웹사이트 상의 플레이스홀더가 실제 이미지로 자동 교체됩니다.

---

### 권장 파일명 목록
1. `project_01.jpg` (또는 `.png`) : 프로젝트 1 - [만 2세] 사계절 자연 생태 놀이 프로그램
2. `project_02.jpg` (또는 `.png`) : 프로젝트 2 - [문서 행정] 엑셀 표준 보육일지 및 관찰 체크리스트
3. `project_03.jpg` (또는 `.png`) : 프로젝트 3 - [교구 제작] 친환경 업사이클링 감각 발달 촉감놀이 교구
4. `project_04.jpg` (또는 `.png`) : 프로젝트 4 - [학부모 소통] PPT 신학기 오리엔테이션 자료
5. `project_05.jpg` (또는 `.png`) : 프로젝트 5 - [안전/보건] 영유아 안전사고 예방 매뉴얼 및 점검표

---

### 권장 이미지 규격
- **비율:** 16:9 또는 3:2 가로형 권장
- **권장 해상도:** 1200 x 800 px 이상
- **용량:** 장당 2MB 이하 권장 (웹 최적화)
